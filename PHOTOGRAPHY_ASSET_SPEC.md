# Nirvana Massage Studio — Photography & Asset Spec

> What images/assets the site actually needs, and how they should look/feel to match `DESIGN_SPECS.md`.

---

## 1. Visual direction (from the brand book)

- Soft, natural styling — linen, candles, stone, dried flowers, muted textures. Not glossy commercial spa stock photography.
- Warm, low-contrast, slightly desaturated color grading that sits comfortably against the sage/taupe/white palette — avoid punchy saturated color that fights the brand palette.
- Natural light preferred over hard studio lighting.

## 2. Asset inventory needed

| Asset | Used where | Notes |
|---|---|---|
| Hero image/photo | Home page hero | Should read calm and spacious — plenty of negative space for the slogan overlay |
| Therapist photo | About page, Booking flow Step 1 | Candid, natural — matches the tone of the reference image shared (warm, outdoor/natural light, genuine smile), not a stiff studio headshot |
| Treatment/service photos | Services page | One per treatment type, ideally consistent styling (same lighting/set) so the page doesn't feel like a stock-photo grab-bag |
| Studio interior photos | About/Contact pages | Shows the actual space — builds trust, especially important since bookings happen online before the client ever visits |
| Texture/background elements | Site-wide, subtle | Soft dot-grid / halftone circle motif (from the logo mark) used as background texture — this can be generated/vector rather than photographed |
| Favicon / app icons | Browser tab, mobile home-screen bookmark | Derived from the circle mark |
| Social share image (Open Graph) | Link previews when the site is shared | One clean composed image combining logo mark + slogan |

## 3. Sourcing

- Therapist and studio-interior photos: need to be actually photographed — no template/stock alternative maintains the personal, trust-building quality this brand relies on (per the About-the-Therapist reasoning in `DESIGN_SPECS.md` §4a).
- Treatment photos: could be sourced from a licensed stock library if original photography isn't available, but should be color-graded to match rather than used as-is.
- Texture/background elements: no photography needed — these are better as vector/generated assets matching the exact brand palette.

## 4. Technical specs

- Deliver source images at high resolution; site should serve responsive/optimized sizes (not full-res originals) for performance.
- Consistent aspect ratios per use-case (e.g. all treatment photos same crop ratio) so the Services grid stays visually even.
- Alt text required for every image, in all three languages, for accessibility and SEO.
